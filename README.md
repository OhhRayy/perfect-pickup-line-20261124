Entry for the [make.fun bounty "The Perfect Pickup Line"](https://make.fun/bounty/u-pucuys-the-perfect-pickup-line-f6725cf6).

## What it does

`main.py` writes one pickup line to `/output/entry.txt`. The program is deterministic (the same
bytes on every run), uses no network, and needs no input.

The line:

> Are you a context window? Because every time I'm near you, I forget everything else I was holding.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
